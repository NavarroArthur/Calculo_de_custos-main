# 🐟 Calculadora de Custos - Beneficiamento de Pescados

Uma aplicação web para calcular os custos de beneficiamento de produtos pesqueiros de forma rápida e intuitiva, com interface responsiva que funciona em desktop, tablet e celular.

## ✨ O que a aplicação faz

- **Calcula os custos de beneficiamento** a partir dos dados da produção (produto, pesos, insumos).
- **Mostra o percentual de beneficiamento** (o ganho de peso do produto).
- **Calcula o custo por Kg** depois do beneficiamento e o custo final da produção.
- **Estima a margem de lucro** quando você informa um preço de venda.
- **Guarda um histórico** dos cálculos para consultar e reaproveitar depois.
- **Exporta relatórios** dos cálculos em PDF.

## 🎯 Principais recursos

- **Validação em tempo real** dos campos, com mensagens de erro claras.
- **Notificações** de sucesso, erro e aviso durante o uso.
- **Sistema de abas** separando a calculadora e o histórico.
- **Duplicação de cálculos** para agilizar cálculos parecidos.
- **Modo offline**: se a conexão cair, o cálculo continua funcionando localmente.
- **Interface acessível**, com navegação por teclado e foco visível.

## 🚀 Como usar

1. Acesse a aplicação no navegador.
2. Selecione o produto desejado.
3. Escolha a categoria da produção.
4. Preencha os dados da produção: preço por Kg, peso inicial, peso final e as quantidades de insumos.
5. Clique em **Calcular Custos**.
6. Visualize os resultados detalhados.
7. Acesse a aba **Histórico** para ver cálculos anteriores ou exportar um relatório.

## 📱 Compatibilidade

Funciona nos navegadores modernos, em desktop, tablet e celular, adaptando-se a qualquer tamanho de tela.
